# VOMAC
VOMAC (Vision-Oriented Modular AI Core) is an experimental modular core
designed to simulate decision-making, reasoning, and system coordination
for future AI-driven software and hardware systems.

## Why VOMAC?
Modern systems require more than isolated models.
They require structured decision pipelines, memory, and controllable logic.

VOMAC focuses on:
- Modular architecture
- Hybrid intelligence (rules + ML)
- System-level thinking
- Long-term extensibility

## Current Status
🚧 v0.1 — Core architecture design phase

## Long-Term Vision
VOMAC aims to become a foundational decision core
that can integrate with APIs, devices, and intelligent services.
